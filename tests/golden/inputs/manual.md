# Atlas Appliance Manual

Welcome to the **Atlas** appliance. This manual covers *installation*, daily use and
troubleshooting. See [the website](https://example.com/support) for videos.

## Installation

Unpack the device and place it on a flat surface.

1. Connect the power cable.
2. Connect the network cable.
3. Press and hold the power button for three seconds.

```bash
# not a heading: this is a shell comment inside a code fence
atlas-cli status --verbose
```

### Network settings

| Setting | Default | Notes |
|---------|---------|-------|
| DHCP    | on      | Recommended |
| Port    | 8443    | HTTPS only  |
